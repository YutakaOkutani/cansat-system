# 20分の実験予算とP6駆動強化

## 時間予算

ミッション開始から1200秒（20分）で終了する。再起動後も経過時間を引き継ぐ。
P4は個別120秒・累積180秒、P5は個別180秒・累積240秒、P6は累積180秒。
P3の累積予算は375秒。P0/P1/P2と遷移猶予を含めて合計1200秒になる。
P4/P5は従来どおり、新しい画像でコーンが見えている場合は個別・累積枠を超えて継続できるが、総20分は超えない。
競技用の13分設定とは異なる、今回のバッテリー制約に合わせた実験設定。

## 動作

| 条件 | 基本動作 | 進捗不足時の一段強化 |
| --- | --- | --- |
| 前進・20cm超 | 0.4秒 / PWM指令70% | 0.6秒 / 75% |
| 前進・8〜20cm | 0.15秒 / 45%（補正後65%） | 0.25秒 / 同出力 |
| 前進・3.5〜8cm | 従来の0.05秒 / 45%（補正後65%） | 強化しない |
| 旋回・20cm超 | 片輪0.15秒 / 65% | 0.30秒 / 75% |
| 旋回・6〜20cm | 従来の片輪0.05秒 / 45% | 0.10秒 / 55% |
| 旋回・6cm未満 | 禁止 | 禁止 |

距離帯を上げる側には2cmのヒステリシスがあり、直前が中距離なら22cmまで強い遠距離動作に戻さない。
近い距離帯への移行は即時停止してから再観測する。3cm以下の停止と成功確認は従来どおり。

前進は停止中に確認した距離、旋回は画像中央からの誤差で進捗を評価する。
前進の実出力累積3秒で改善0.5cm未満、旋回の実出力累積0.6秒で正規化画像誤差の改善0.02未満なら一段強化する。
強化後の評価区間でも改善しなければ `GOAL_NO_PROGRESS` で終了する。
実出力はPWM指令が出ていた時間であり、車輪の回転を測った値ではない。

最大要求回数は前進120回・旋回60回。実出力予算は前進60秒・旋回20秒。
回数・時間・強化状態はP6再入やミッション再起動でも戻らない。
欠測時は直ちに停止し、終了までの観測猶予を20秒に延長。
P5復帰は従来の品質条件と6秒の待ちを維持し、最大5回へ増やす。

## 長い動作の途中停止

新しい動作の開始と成功確認には、停止・整定後の新しい同期観測が必要。
動作中だけ、期限内の画像と新しい超音波による継続を認める。動作許可の期限は更新しない。
20ms周期のモータ処理が、画像・超音波の無効化、近距離帯への移行、中央到達、時間・出力予算を監視する。
OSのスケジューリングによる停止遅延はあり得る。

遠距離旋回中の意図した方位変化は、従来の5度変化停止の対象から分離する。
開始時に新しいIMU方位があれば累積角・開始方位との差が15度で停止し、途中でIMUが古くなっても停止する。
IMU方位が開始時から使えない場合も、画像・距離・最大パルス時間で制限する。
前進、近距離旋回、停止後の成功確認では従来の姿勢変化による停止・票の破棄を維持する。

## 設定と更新後の実行

既存の`mission.toml`はそのまま使える。省略時も今回の新しい既定値になる。
`mission.toml.example`の任意の`[approach]`で時間・PWM・実出力予算を調整できる。
起動前に型・有限値・範囲・強化値の整合を検証し、実効値はrun manifestにも記録する。

以前の制御版や異なる接近設定の保存ミッションは自動再開しない。
新しい試験を始める場合は、停止中に `python3 -m mission.recovery status` で状態を確認し、
`python3 -m mission.recovery reset` で以前のミッションを明示的にリセットする。
リセットは既存の再起動用予算を消すので、同じ試験の途中再開には使用しない。
今回の作業では実機の保存状態をリセットしていない。

## ログと検証

CSVスキーマ7には要求時間・PWM・距離帯、実出力時間、進捗と強化状態、P5復帰回数を追加した。
`GOAL_OUTPUT_TIME_LIMIT`は実出力予算切れ、`GOAL_REAPPROACH_LIMIT`は復帰回数切れで、いずれも成功ではない。
保存中の動作許可の残り時間は予約分として保存し、突然の再起動で出力予算が戻ることを防ぐ。

`python3 -m unittest discover -s runs/spec -q`で全仕様テストを実行する。
`runs/spec/approach_strength.py`は本番の出力変換を仮想GPIOにつなぎ、出力時間・PWM、
長い動作の途中停止、意図した旋回、至近距離成功、段階強化、無進捗終了を検証する。
実機走行は未実施。PWMやパルス長は実機の移動量を保証する値ではなく、試走で調整する初期値。

検証結果: 全324仕様テスト成功、`git diff --check`成功。
近距離の時刻一致条件と6cmちょうどでの従来の旋回許可も回帰テストで確認した。
既存のモータ補正テストは0.90の固定フィクスチャと実機設定1.00の確認を分け、
実機の左右補正値を変更せずに出力変換を検証する。
